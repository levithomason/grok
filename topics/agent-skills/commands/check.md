Give me a concise check list at the product owner level.

Never mark an item so it renders struck through. That means no `~~text~~`, no Unicode strike characters, and no markdown checkboxes (`- [x]` / `- [ ]`) — the display renders a checked box as strikethrough, which makes the text unreadable and I need to read every line. Mark status some other way: an emoji prefix (✅ ⬜ 🚧), a plain bullet with a word, or whatever fits what you're showing. Not every item needs a status.
